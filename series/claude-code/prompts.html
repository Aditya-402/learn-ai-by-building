Chapter 8 · A standup that runs on its own

Type in PowerShell (Mac: Terminal)
git log --since=yesterday --oneline | claude -p "turn this into a three-line standup"

Headless: pipe text in, get the answer, done.

Type in PowerShell (Mac: Terminal)
claude -p "Read data/tasks.json and the git log since yesterday; write a three-line standup to data/standup.md" --allowedTools "Read,Write,Bash(git log:*)"

Only the tools it needs.

Type into Claude Code
Wrap that headless standup command in standup.ps1, so I can run it with .\standup.ps1 from this folder. Keep the same allowed tools.

A new session cannot see your terminal history: give it the exact command when it asks.

Windows · PowerShell
.\standup.ps1
Mac · Terminal
Ask for standup.sh instead, then: ./standup.sh

One command, every morning.

Chapter 11 · DevPulse tools for Claude

Type into Claude Code
/plugin install mcp-server-dev@claude-plugins-official

The official plugin that builds MCP servers.

Type into Claude Code
/mcp-server-dev:build-mcp-server A local stdio server in Python, mcp/devpulse_mcp.py, using the open-source MCP Python SDK in a .venv. Three tools on data/tasks.json: log_task(title, tag, minutes), list_today(), week_summary(). Reuse the validation rules from server.py.

A complete brief, so it can skip its questions. The rule: a stdio server never prints to stdout.

Windows · PowerShell
claude mcp add devpulse -- .venv/Scripts/python.exe mcp/devpulse_mcp.py
claude mcp get devpulse
Mac · Terminal
claude mcp add devpulse -- .venv/bin/python mcp/devpulse_mcp.py
claude mcp get devpulse

Run from the project folder. You should see ✓ Connected.
