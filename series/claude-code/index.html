Start here

DevPulse is a small tracker: you type what you worked on and for how long, and it shows your day, your week and your streak. We build it with Claude Code, one chapter at a time.

Each chapter starts with a problem we hit while building. Then we find the Claude Code feature that solves it, and use it at once. Each chapter has a video, the episode with the same number, and a page here with every command to type. Start with Chapter 0.

Every prompt in one place: all the prompts and commands, ready to copy, chapter by chapter.
