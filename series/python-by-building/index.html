Four friends plan a weekend trip from Bengaluru. Every chapter adds one feature to their app: greet us, split the bill, check the budget, find the weather. Each feature runs into a challenge, and the challenge is where the next piece of Python comes in.

Each chapter has a video, and a page here. The page teaches the same ideas again, with plenty of practice, and a step of your own app. Start with Chapter 0.
