Start here

You have used a chatbot in the browser. You type a question, an answer comes back. But what happens in between? And how do you get that answer inside a program of your own?

In this series we build one chatbot, a shop assistant for an electronics shop. It starts as a few lines of Python that send one question to Gemini and print the reply. Then it hits a wall, and the wall tells us what to build next. It forgets your name, so it gets a memory. It knows nothing about this year, so we give it a product sheet. It cannot see today's prices, so it gets a tool. By the end, it uses two tools in a row on its own: your first agent.

We do not type the code line by line. We write a clear prompt, Antigravity writes the code, and we read it, run it and see what it does. A clear prompt is the steering wheel, so every prompt is on the page.

Each chapter has a video, the episode with the same number, and a page here. Start with Chapter 1.

Who it is for

This series is for you if you can read a little Python, run a script, and now want to build something real with an AI model. You do not need any machine-learning background.

Never written Python? Start with Learn Python by Building a Trip Planner, and come back here.
