How do I install Claude Code?

Want to build with Claude Code, the AI that works in a folder on your own computer? By the end, you will have it installed and signed in on Windows or Mac, checked with two commands, and ready to start building.

What you need first

Claude Code is an AI that works inside a folder on your own computer. It reads your files, writes code and runs commands, asking you before it changes anything. Let's get it running.

You need three things before you start:

  • A paid Claude plan. Claude Code is not part of the Free plan; Pro is the smallest plan that includes it.
  • A 64-bit computer: Windows 10 (version 1809 or later) or Windows 11, or macOS 13 or later.
  • About 10 minutes, and an internet connection that is not blocked by an office proxy.

Install it on Windows

It takes two steps, both in PowerShell.

1

Open PowerShell

Press the Windows key, type PowerShell, and open Windows PowerShell. Do not pick the one marked (x86); that is the 32-bit version, and Claude Code needs 64-bit.

2

Run the installer

Paste this line into PowerShell and press Enter:

Paste into PowerShellirm https://claude.ai/install.ps1 | iex

When it finishes, close PowerShell and open a new one, so it can find the new command. Then check it:

Then typeclaude --version
What you should see2.1.312 (Claude Code)

Your number may be newer; that is fine. What matters is the words (Claude Code). The native installer also keeps Claude Code up to date by itself.

Install it on a Mac

Open Terminal (press Cmd+Space, type Terminal), paste this line and press Enter:

Paste into Terminalcurl -fsSL https://claude.ai/install.sh | bash

Open a new Terminal window and type claude --version. You should see a version number followed by (Claude Code), as on Windows. Linux works the same way, with the same line.

Sign in and say hello

Claude Code always works inside a folder, so make one first and start it there.

Windows (PowerShell)mkdir C:\code\hello cd C:\code\hello claude
Mac (Terminal)mkdir -p ~/code/hello cd ~/code/hello claude

The first time, Claude Code opens your browser to sign in. Sign in with the Claude account that has your Pro plan, then come back to the terminal.

It then asks whether you trust the files in this folder. This is your own empty folder, so choose yes.

Now type /status and press Enter. You should see your account, the model and the version. Type /exit to leave.

Keep your folders simple

Use a folder like C:\code, with no spaces and not inside OneDrive. Synced folders and spaces in paths cause odd errors later.

Check that everything works

Claude Code has a built-in health check. Run it in PowerShell or Terminal, outside a Claude session:

Then typeclaude doctor

It looks at your installation and tells you if anything needs fixing. If it reports a problem, the next section has the usual fixes.

When the install goes wrong

Read the message first; it usually names the problem. These are the common ones.

What you seeWhat it means, and the fix
irm is not recognizedYou are in Command Prompt, not PowerShell. Open PowerShell and paste the line again.
claude is not recognized, or command not foundClose the terminal and open a new one first. If it still fails, the installer's folder is not on your PATH; the fix is below.
A 32-bit errorYou opened Windows PowerShell (x86). Use the one without (x86).
A 403 error, or a certificate errorAn office network or proxy is blocking the download. Try a home network or your phone's hotspot. A 403 can also mean Claude Code is not offered in your country yet.
The browser sign-in says your plan does not include Claude CodeThe account is on the Free plan. Upgrade to Pro, then run /login inside Claude Code.

If claude is not recognized keeps coming back on Windows, add the installer's folder to your PATH with this line, then open a new PowerShell:

Paste into PowerShell[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$env:USERPROFILE\.local\bin", "User")

Still stuck? Anthropic's installation troubleshooting page covers the rarer cases.
