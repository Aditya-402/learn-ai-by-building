Let's try to understand.</p><h3>Python means two things</h3><p>First, what is Python? When programmers say Python, they mean two things. English is a good way to see both.</p><p>English has words, and grammar rules for putting them together. "Get me water" makes sense, but "Water get me" does not. The words are the same; one change in order, and the meaning is gone.</p><p>Python, the language, works the same way: a set of words, and the rules for writing them. These grammar rules are what we call <b>syntax</b>.</p><p>The second thing is the interpreter. In everyday English, an interpreter is the person who stands between two people who don't share a language.</p><figure><img src="https://aditya-402.github.io/learn-ai-by-building/blog/what-is-a-python-program/medium/interp-people-interp-python.png" alt="An interpreter between two people: Bonjour on one side, Hello on the other &#183; You, then Python in the middle, then the computer"><figcaption>An interpreter stands between two sides. Python's interpreter stands between you and the computer.</figcaption></figure><p>Python's interpreter does the same job. Like a broker, it stands between you and the computer. It reads what you wrote, and gets the computer to do it.</p><p>So when you press Run, you are not talking to the computer directly. You are handing your program to the interpreter.</p><h3>So, what is a Python program?</h3><p>A Python program is just text. You type it, and save it in a file whose name <a href="https://docs.python.org/3/tutorial/modules.html">ends in .py</a>, like <code>hello.py</code>. That file is your program.</p><figure><img src="https://aditya-402.github.io/learn-ai-by-building/blog/what-is-a-python-program/medium/hello-py.png" alt="A text file named hello.py"></figure><p>Nothing special happens while you type. A <code>.py</code> file is plain text, the same as a note on your phone. Everything happens when you press Run.</p><h3>What happens when you press Run</h3><p>Follow one program from your keyboard to the screen, in three moves.</p><p><b>When you press Run:</b> it reads the whole file &#8594; turns it into simple steps &#8594; runs them, top to bottom</p><p>The interpreter first reads the whole file, from the first line to the last, and checks the grammar. Then it turns your code into small, simple steps. Only then does it start running those steps, top to bottom.</p><p>These simple steps are what we call <b><a href="https://docs.python.org/3/glossary.html">bytecode</a></b>. You never see them, and you don't need to.</p><h4>Curious? Peek at the bytecode (optional)</h4><p>Python has <a href="https://docs.python.org/3/library/dis.html">a tool called dis</a> that shows the simple steps it makes from your code. Press Run to see the steps for one line, <code>print("Hello")</code>. Don't try to learn them; just notice that one line of yours becomes several small steps.</p><pre>import dis
dis.dis(&#x27;print(&quot;Hello&quot;)&#x27;)</pre><h3>The careful cook</h3><p>Say you are cooking from a new recipe. A careful cook reads the whole recipe first. If one sentence in it makes no sense, he doesn't start cooking at all.</p><figure><img src="https://aditya-402.github.io/learn-ai-by-building/blog/what-is-a-python-program/medium/cook-reads-cook-stops.png" alt="A cook reading the whole recipe card, the stove still off &#183; The same cook frowning at one scribbled line on the card"><figcaption>First he reads it all. One line makes no sense, so he never starts.</figcaption></figure><p>If the recipe reads fine, he starts at step 1 and cooks step by step, top to bottom.</p><p>Python's interpreter is that careful cook. Reading the whole recipe first is what we call <b>compiling</b>. Cooking it step by step is what we call <b>interpreting</b>.</p><blockquote><b>Key idea:</b> Every time you press Run, Python's interpreter does two jobs. First it compiles: it reads the whole file. Then it interprets: it runs it, step by step.</blockquote><h3>The puzzle, answered</h3><p>Now back to the puzzle. Line 3 is missing its bracket, so the grammar check fails, and the interpreter never starts running. Not one line runs, so nothing is printed, not even Hello.</p><p><b>What the puzzle shows:</b></p><pre>SyntaxError: &#x27;(&#x27; was never closed</pre><p>A grammar mistake is what we call a <b><a href="https://docs.python.org/3/tutorial/errors.html">syntax error</a></b>. One syntax error anywhere in the file, and nothing runs.</p><h4>Try it: fix the bracket</h4><p><b>The step:</b> on the line marked <code># edit here</code>, add the missing <code>)</code> right after <code>"Bye"</code>. Bye</pre><p><b>What it means:</b> all 3 lines run, because the grammar check passed and the cook started cooking.</p><blockquote><b>Careful here:</b> You may read that an interpreter runs code line by line. If you guessed that Hello and Line two would print, you were thinking exactly that. For Python, it is only half the story: Python compiles the whole file first, which is why nothing printed.</blockquote><h3>How is this different from C?</h3><p>So what does a compiler do in a language like C? It stops after the first job. It turns your whole program into a separate program file, an <code>.exe</code> on Windows, which you can run later as many times as you like.</p><p><b>Python:</b> press Run &#8594; compile &#8594; interpret<br>both jobs, every time you press Run</p><p><b>C:</b> compile &#8594; a separate program file<br>you run that file later</p><p>You don't need C to learn Python. It is here only so that the word <i>compiler</i> means something to you the next time you meet it.</p><h3>Where the interpreter comes from</h3><p>Where do you get this interpreter? Normally, you download it from <a href="https://www.python.org/downloads/">python.org</a> and install it on your computer. That download is the interpreter. It is called <b>CPython</b>, because <a href="https://docs.python.org/3/reference/introduction.html">it is written in C</a>.</p><figure><img src="https://aditya-402.github.io/learn-ai-by-building/blog/what-is-a-python-program/medium/download.png" alt="Downloading the Python interpreter from python.org onto a laptop"></figure><p>To make learning easy, we have already put the interpreter on our website.
